# RuSecure

**RuSecure** — утилита для macOS, которая работает как браузер по умолчанию и маршрутизирует ссылки: российские сайты открывает в одном браузере, все остальные — в другом.

Например: Госуслуги и другие российские сервисы открываются в Яндекс Браузере, а весь остальной интернет — в Safari или любом другом браузере по вашему выбору.

## Возможности

- 🧭 **Маршрутизация ссылок** — RuSecure регистрируется как обработчик `http`/`https` и перенаправляет каждую ссылку в нужный браузер.
- 🌐 **geosite category-ru** — база российских доменов из [v2fly/domain-list-community](https://github.com/v2fly/domain-list-community), обновляется автоматически раз в сутки.
- 🇷🇺 **Зоны .ru и .рф** — отдельное правило для доменных зон.
- ➕ **Свои списки** — добавьте любой сайт в «Российские сайты» или в «Исключения».
- 🔍 **Строка поиска** — оверлей по `⌥Space` из любого приложения, с подсказками Google / Яндекса / DuckDuckGo.
- ⚙️ **Настройки** — выбор браузеров и поисковика из списка установленных в системе.

## Как определяется «российский» сайт

Правила проверяются по приоритету:

1. **Исключения** — сайт никогда не считается российским.
2. **Список российских сайтов** — сайт всегда считается российским (по умолчанию: `gosuslugi.ru`, `nalog.gov.ru`, `mos.ru`, `gosuslugi.mosreg.ru`, `kremlin.ru`, `government.ru`).
3. **geosite category-ru** — если включён в настройках.
4. **Зоны `.ru` / `.рф`** — если включены в настройках.

Если ни одно правило не сработало, ссылка уходит в браузер «для остальных сайтов». Если выбранный браузер не найден, используется второй как запасной.

## Требования

- macOS 26.5 или новее
- Xcode для сборки

## Сборка

Откройте проект в Xcode и соберите (`⌘B`) либо через терминал:

```bash
xcodebuild -project RuSecure.xcodeproj -scheme RuSecure -configuration Release build
```

Собранный `RuSecure.app` появится в Derived Data (Xcode → Product → Show Build Folder in Finder). Переместите его в `/Applications`.

## Назначение браузером по умолчанию

1. Запустите RuSecure один раз.
2. Откройте **Системные настройки → Рабочий стол и Dock → Браузер по умолчанию**.
3. Выберите **RuSecure** в списке.

Готово: теперь все ссылки из любых приложений проходят через RuSecure.

## Если macOS не даёт открыть приложение

RuSecure распространяется без подписки и нотарилизации Apple Developer Program, поэтому Gatekeeper блокирует скачанные сборки. Это нормально для неподписанных приложений. Снимите карантин одной командой:

```bash
xattr -cr /Applications/RuSecure.app
```

или откройте приложение через **правый клик → Открыть** и подтвердите запуск.

При сборке из Xcode на своей машине подписка не требуется: проект использует ad-hoc подпись и запускается сразу.

## Приватность

- RuSecure не собирает данные и не имеет аналитики.
- Единственный сетевой запрос — скачивание списка geosite с GitHub (раз в сутки, кэш хранится в `~/Library/Application Support/RuSecure/geosite_category_ru.yml`).
- Настройки и списки сайтов хранятся локально в `UserDefaults`.
